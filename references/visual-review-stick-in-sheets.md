# Stick-in-sheets visual review

Use this file only when `ARTEFACT` is `stick-in sheets`.

**Cut guides and page breaks.** The teacher prints this once, cuts along the dashed guides, and every child's set has to come off together. A cut set straddling a page turn falls apart in the cutting, so check that each child's block sits whole on one page, or takes its own pages cleanly when it is too big for one. The pack comes to you as the PDF Chrome printed, so what you see is what cuts: a set straddling a page turn is a certain fault.

**Figure fidelity.** Each write-on piece reproduces a moment the class met on the board, so the figure has to be the same figure, drawn to the same values the spec states, with its write-on space intact and large enough for a child's handwriting.
