Design a Year 4 science lesson for this objective: "Identify the different types of human teeth and their uses."

Two things about this environment before you start:

1. There is no shell here, so no Python is available. Do not try to run the scaffold script, write lesson-design.json or photo-requirements.json, or run the validator. Read any reference files you need directly instead of through a script.
2. What is wanted is the lesson itself, written as a walk-through a teacher could teach from, slide by slide, in the order the class meets it. Save it as design-decisions.md in the current directory.

Make every pedagogical decision as you normally would, and write the walk-through in full.
