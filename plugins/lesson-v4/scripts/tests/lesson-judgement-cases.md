# User-fit regression cases

These are evaluation inputs and expected distinctions, not additional runtime instructions or results from model trials. Use the same brief, source material and scoring criteria for baseline and candidate. A schema pass, matching review count or confident PASS does not score a case.

For the next behavioural comparison, budget one baseline and one candidate design for each of the eight cases below (16 design-only trials). Score before seeing the rationale. Stop after that batch and report failures and regressions before choosing further work; do not keep generating until a preferred answer appears. Full resource generation and teacher feedback are separate evidence.

| Case | Required distinction | Failure to catch | Similar-looking choice to preserve |
|---|---|---|---|
| Y4 partitioning four-digit numbers; plan requires expanded form, place-value words, zero and out-of-order parts | Show a specific number, model its contributions concretely, make live working possible, prepare fresh practice | Generic narration, a filled reference occupying all working space, or independent recomposition never prepared | Keep the plan's required forms and cases; do not require both recording forms on every question |
| Y4 continuity and change in children's lives using sources | Establish enough period context, teach one intelligible aspect through a useful source, then children use it before the next aspect | First source comparison demands several unintroduced contexts and thinking moves; fresh work adds an untaught relationship | A brief orientation moment, useful source vocabulary and a focused inference model may be necessary; no compulsory timeline or source taxonomy |
| Modern reading-and-writing timetable compared with historical account of learning reading before writing | Restrict conclusions to what the evidence establishes | The timetable is treated as proof of when modern children first learn writing | The timetable can establish which activities occur in that session; a reliable account of learning sequence could support the broader question |
| Science: one photograph of a plant, then dated height measurements | Separate current state from change over time | Infer growth rate from one size snapshot | Infer change across the supplied dated measurements, within their scope; do not reject all inference |
| English: model how punctuation changes the meaning of a supplied sentence | Concrete spoken choices and visible annotation of the sentence | A generic checklist replaces the model, or the answer prohibition suppresses the actual words being modelled | Text is the teaching object; no compulsory illustration or separate working box |
| PE: an unfamiliar safe movement demonstrated with equipment | Let children watch and then attempt the movement with necessary cues | A long sequence of screen explanation or a compulsory written model delays the action | The screen can be minimal; no space for written working is needed |
| Inspect an already completed worked example to explain an error | Choose the starting state from the learning action | Blank out the example merely because live modelling is usually useful | A complete prepared example is appropriate; children still make the explanation |
| Supported comparison practice followed by an explicitly unaided recall check | Match available support to the decision being assessed | Remove useful sources/criteria from practice, or expose the recall answer during the check | Keep support for reasoning when it does not supply the decision; remove it for the specific unaided check |

Check all cases for accurate objective coverage, natural child-facing language, achievable pacing, useful vocabulary at the point of need and preserved source meaning. The maths and history walkthroughs are examples of Daniel's decisions, not universal slide templates.
