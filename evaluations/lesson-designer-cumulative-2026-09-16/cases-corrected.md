# Corrected case pack: the key

Written 16 September 2026, after the review of the pushed branch. Evaluation material, not runtime guidance. The original pack (`cases.md`, `blind-cases.md`) and its result (`review.md`, sixteen of sixteen matched) are kept unchanged as a developmental check. This file is the key to `blind-cases-corrected.md`, which a blind reviewer reads instead.

## Why the pack was corrected

The review found that the original blind cases were not blind enough, and that some expected judgements claimed more than the case supported:

- **The headings gave the diagnosis away.** `A printed cross recorded as understanding`, `made deeper with rules nobody taught` and `the same question twice, called deeper` told the reviewer the criticism before it judged. The corrected pack gives each case a neutral id and its subject only, in a shuffled order, so the ids do not line up with the originals.
- **C02** accepted "he couldn't earn his own money", but missing shoemaking training does not show Will could never earn anything. The response and the expected reason now stop at the trade.
- **C09** asked what had changed with only Victorian evidence on the board. A modern classroom photograph is now supplied, and the timetable question names the class timetable children compare against.
- **C13** described a river map without giving its connections, so nobody could check the answer. The network is now written out, and the answer can be verified: C and E only.
- **C14**'s reason said the response creates "no atmosphere". That is too strong: the task never asks for a chosen atmosphere, so the response cannot show whether one was chosen.
- **C07**'s reason treated a partner's report as proof that every child understood. A partner's report is one pair's reason and a chance for every child to form one; it is not proof for the class.
- **Subject balance.** Nine of the sixteen original cases were history. Three history cases whose point another case already covers (C04 untaught hardship, which C03's untaught rules also covers; C05 an all-or-nothing key, which C12 also covers; C08 the same question twice) are replaced by the three weak tasks already written in `task-contrasts.md` for maths, science and geography. The corrected pack is still weighted to history and has one case each for English, RE and PSHE, so it cannot show well-calibrated judgement across all seven subjects.

The verdict balance is unchanged: seven PASS, eight REVISE, one BOUNDED CORRECTION.

## Re-review of the corrected pack

One fresh Claude Opus 5 assignment read only `blind-cases-corrected.md`: no key, no report and no plugin guidance, so it judged as a teacher reading the cases rather than as the plugin's reviewer. Its answers are in `review-corrected-neutral.md`.

**Fifteen of sixteen verdicts matched the key.** The one difference is K08 (the English `add two adjectives` task): the key says REVISE, the re-review said BOUNDED CORRECTION, reasoning that rewording the task to name the atmosphere and the taught move would be enough. That is a defensible reading, since the phrase itself is not the problem and the fix is to the task's wording; the key keeps REVISE because the design's claim for the beat is wrong as well as the task. The re-review's own reason also said the response creates "no atmosphere", the same overstatement this pack corrected in the key.

**What this does and does not show.** The cases no longer tell the reader the diagnosis, and a reader without the plugin's guidance reached nearly the same verdicts, which suggests the expected verdicts are not simply the plugin's own standards read back. It is still one run, by the same model family that wrote the cases, and not independent human confirmation. It says nothing about whether the plugin's reviewer judges these cases well, and it is not evidence that generated lessons improved.
